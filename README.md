# 🏨 Hotel Reservation System

A Java-based Hotel Reservation System developed as part of the **CodeAlpha Java Programming Internship**. This project allows users to search available rooms, book hotel rooms, cancel reservations, manage bookings, process payments, and store reservation details using file handling.

## 📌 Features

- Search available hotel rooms
- Book hotel rooms
- Cancel reservations
- View reservation details
- Process payments
- File handling for saving reservations
- Object-Oriented Programming (OOP)

## 🛠️ Technologies Used

- Java
- Object-Oriented Programming (OOP)
- File Handling
- VS Code
- Git
- GitHub

## 🚀 How to Run

1. Clone the repository.

```bash
git clone https://github.com/reddyanusha1800/CodeAlpha_HotelReservationSystem.git
```

2. Open the project in VS Code.

3. Compile all Java files.

```bash
javac *.java
```

4. Run the project.

```bash
java HotelReservationSystem
```
